## What is here

* `imports/<repo>/` — the `.lean` files, the Lake files (`lakefile.*`, `lean-toolchain`, `lake-manifest.json`) and any license that third-party code requires, at the same paths as in the source repository. Nothing else from the private repositories is published (documents, prompts, commercial material).
* `mvei/<repo>/` — the kernel result for that repository: `README.md` (summary, how to reproduce), `VERIFICACAO.json` (each theorem, its statement and its axioms), `TEOREMAS.csv` (each declared `theorem`/`lemma` with file, line and state), `BUILD_LOG.txt`, `SOURCE.json` (source commit and date) and `SOURCES.sha256` (check with `sha256sum -c mvei/<repo>/SOURCES.sha256` from this folder).

*Closed* means the kernel accepted the proof and it depends only on `propext`, `Classical.choice` and `Quot.sound`: the statement written in the file is proved. It is not a claim that an open problem is solved, and many closed statements are about objects defined in the same file. *Conditional* means the proof uses axioms declared in the repository; *open* means it uses `sorry`. *Numbered families* are closed theorems whose name repeats a pattern 20 or more times (`precedence_0001`, `precedence_0002`, …): the sign of a file generated by a program, usually proving values written in the same file. In `mishkan-iii-core`, 10 104 of the conditional theorems depend instead on axioms of the MVEI name layer (hypotheses MVEI chose so that generated files compile; see [`mvei/mishkan-iii-core/README.md`](mvei/mishkan-iii-core/README.md)).
